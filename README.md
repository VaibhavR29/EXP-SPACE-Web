## 🌟 Key Features

- **Obsidian Space HUD Interface:** High-contrast aerospace aesthetics, responsive typography, and glowing telemetry indicators.
- **Live Telemetry Ticker:** Real-time UTC clock, orbital tracking (400 km LEO at 7.82 km/s), Aditya-L1 halo orbit status, and coordinates.
- **Interactive 3D Earth (Three.js):** Day/night shading, cloud layer, atmospheric Rayleigh glow, and an orbiting Gaganyaan crew module with drag-to-rotate interaction.
- **Cosmic Sonification Studio (Web Audio API):** Real-time synthesizer transforming pulsar frequencies (PSR B1919+21), black hole acoustic echoes, and solar wind streams into audio with a live 256-bin FFT spectrum visualizer.
- **Interactive Solar System Orrery:** Real-time planetary orbital motion with click-to-scan telemetry for Mercury, Venus, Earth, Mars, Jupiter, and Saturn.
- **Gaganyaan Launch Simulator:** Interactive flight envelope tracking LVM3 ascent from Sriharikota through stage separations to orbital insertion.
- **India's Space Legacy:** Interactive mission dossiers for Chandrayaan-3, Mangalyaan, Aditya-L1, Gaganyaan, Bharatiya Antariksh Station (BAS), and Shukrayaan.
- **Deep Space Transmission Console:** Uplink terminal to connect with scientists, engineers, and researchers worldwide.

## 🛠️ Tech Stack

- **Core:** Semantic HTML5, Modern CSS3 (CSS Variables, Glassmorphism, CSS Grid)
- **3D Graphics & Canvas:** WebGL, Three.js, Canvas 2D
- **Audio Synthesis:** Web Audio API (Analysers, Oscillators, Biquad Filters, LFOs)
- **Zero Heavy Dependencies:** High-performance, offline-ready, and lightning fast.
